# Agents Overview

This directory will contain the modular AI agents for the AI Enterprise Simulator.

- **core/** – Shared utilities and base classes for agents.
- **ceo/** – CEO Agent implementation.
- **market/** – Market Research Agent.
- **finance/** – Finance Agent.
- **product/** – Product Agent.
- **marketing/** – Marketing Agent.
- **decision/** – Decision Engine that coordinates agents.

Each sub‑folder will eventually include its own `README.md` and Python modules.
